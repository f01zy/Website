# About

Simple cloth simulation, written in Raylib, what allows dragging cloth and pinning points. Each point of the cloth is connected to its nearest neighbors by super-elastic springs, allowing the entire system to behave like cloth.

# Controls

## Keyboard

| Key | Action                             |
|-----|------------------------------------|
| <kbd>Q</kbd>   | Pin the cloth's top-left point     |
| <kbd>W</kbd>   | Pin the cloth's top-right point    |
| <kbd>A</kbd>   | Pin the cloth's bottom-left point  |
| <kbd>S</kbd>   | Pin the cloth's bottom-right point |
| <kbd>R</kbd>   | Reset the cloth's position         |
| <kbd>F1</kbd>  | Enable wireframe mode              |

## Mouse

| Key          | Action                    |
|--------------|---------------------------|
| MOUSE LEFT   | Rotate the camera         |
| MOUSE RIGHT  | Drag the cloth            |
| MOUSE SCROLL | Zoom the camera in or out |
